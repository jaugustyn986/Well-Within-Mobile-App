# Well Within Social Workspace

Last updated: 2026-07-04

This folder is the operating system for Well Within social growth. The July 2026 reset changed the default behavior: do not generate daily Instagram content packages just because the queue has ideas. The work now runs through audience learning, hypothesis tests, and weekly decisions.

## Current Source Of Truth

Read these first, in order:

1. `SOCIAL_GROWTH_RESET_2026-07-04.md` - strategic reset and operating principles.
2. `SOCIAL_METRICS_DASHBOARD.md` - live Instagram account/post metrics and decisions.
3. `SOCIAL_HYPOTHESIS_BACKLOG.md` - the only approved source for new content hypotheses.
4. `SOCIAL_30_DAY_EXECUTION_PLAN.md` - current operating plan.
5. `INSTAGRAM_AUTOMATION_RUNBOOK.md` - how automations should run.
6. `SOCIAL_AUTOMATION_INVENTORY.md` - which scheduled jobs exist and what they are allowed to do.

## Current Operating Cadence

| Cadence | Job | Output |
| --- | --- | --- |
| Daily | Audience intelligence | Exact audience language, objections, source patterns, candidate hypothesis implications. |
| Weekly | Growth decision review | Decide whether one hypothesis is ready for a bounded test or whether more research is needed. |
| Manual only | Content package | One review-ready test package, only after the hypothesis gate passes. |

## Generated Content

The `generated/` folder contains old drafts and assets. Some were published, some were only drafts, and the July 4 packages are paused/not approved. Do not infer approval from the presence of a generated folder.

## Reports

Weekly strategy outputs belong in `reports/YYYY-MM-DD-weekly-growth-brief.md`.

## Cleanup Rule

Do not delete old social docs or assets during routine automation runs. If cleanup is needed, write a short cleanup proposal first and get manual approval before moving or deleting history.
