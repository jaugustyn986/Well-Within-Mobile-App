# Well Within Social Hypothesis Backlog

Last updated: 2026-07-04

This backlog is now the only allowed source for new Instagram content packages. A content package may be drafted only when it selects one hypothesis, one content role, one target metric, one visual system, and one decision rule.

## Evidence Levels

| Level | Meaning | Allowed action |
| --- | --- | --- |
| 0 | Opinion only | Research/listening only. No post. |
| 1 | External evidence only | One low-cost test if measurement exists. |
| 2 | External evidence plus weak internal signal | One organic test with explicit stop/scale rule. |
| 3 | Repeated internal signal | Variant tests or small paid amplification. |
| 4 | App funnel signal | Scale, paid test, creator test, or lifecycle integration. |

## Priority Hypotheses

### H1: Human Anti-Prediction Positioning

People who distrust fertility apps may respond to a clear human/founder voice that says what Well Within will not do: it will not predict, overclaim, sell certainty, or make the chart speak louder than observations.

| Field | Value |
| --- | --- |
| Evidence level | 2 |
| External evidence | Clue's public positioning emphasizes human, trust-led health marketing; platform guidance favors original Reels content; privacy scrutiny around fertility apps makes trust a real wedge. |
| Internal evidence | Reels are the only format getting double-digit reach; privacy/explanation carousels did not work. |
| Content role | Trust positioning |
| Target metric | Profile visits, follows, saves, meaningful comments or DMs |
| Visual system | Founder/human voice Reel with app cutaways, not a text carousel |
| Decision rule | Continue if reach is >= 20 and there is at least one concrete intent signal: follow, save, profile visit, reply, comment, or DM. |

### H2: Charting Confusion Community Prompt

The account should ask a specific question that creates conversation: "What part of charting felt confusing at first?" The prior static prompt failed distribution, so the idea can only be re-tested in a native format.

| Field | Value |
| --- | --- |
| Evidence level | 2 |
| External evidence | Community-led women-focused apps such as Peanut use identity, conversation, and shared life stage as a growth surface. |
| Internal evidence | The June 13 static prompt had reach 1, so the format failed. The question remains strategically useful because it creates audience language. |
| Content role | Audience research and community |
| Target metric | Comments, replies, DMs, saves |
| Visual system | Reel or Story question with a real person, screen recording, or tactile charting moment |
| Decision rule | Keep if it creates at least one useful audience-language response. If not, move the question to comments on adjacent accounts or practitioner interviews. |

### H3: One Real Daily Entry Demo

Instead of saying "record one observation" again, show the action in context: the user notices one sign, records it, and sees how it sits in the chart without the app making a prediction.

| Field | Value |
| --- | --- |
| Evidence level | 2 |
| External evidence | Mira and Read Your Body both benefit from showing concrete product behavior and charts rather than abstract wellness messaging. |
| Internal evidence | The July 3 observation Reel got the only save; static micro-action posts did not distribute. |
| Content role | Activation education |
| Target metric | Saves, profile visits, bio link clicks, first observation if attribution is available |
| Visual system | App-screen Reel with hand/phone context or crisp screen recording |
| Decision rule | Continue only if it beats the current Reel baseline: reach > 28 or at least two intent signals. |

### H4: Where Cycle Data Goes

Privacy can be a growth wedge, but only if framed around the user's real fear: "Where does my cycle data go?" Abstract privacy claims did not earn attention.

| Field | Value |
| --- | --- |
| Evidence level | 1 |
| External evidence | Fertility and period apps have been scrutinized for privacy and data-sharing practices; trust can differentiate. |
| Internal evidence | The May 31 privacy carousel reached only 2 people with no interactions. |
| Content role | Trust and objection handling |
| Target metric | Saves, shares, profile visits |
| Visual system | Human/founder Reel plus one clear app privacy screen, not a full carousel |
| Decision rule | Do not draft until the exact app privacy claim is reviewed against current product behavior. |

### H5: Practitioner Referral Wedge

Well Within may grow faster by earning trust through fertility-awareness educators, coaches, or adjacent practitioners than by trying to make a tiny Instagram account carry all discovery.

| Field | Value |
| --- | --- |
| Evidence level | 1 |
| External evidence | Fertility apps and women's health products often benefit from expert, creator, or community trust transfer. |
| Internal evidence | Direct social content has not created audience growth yet. |
| Content role | Partnership research |
| Target metric | Five interviews or conversations, two qualified referral hypotheses |
| Visual system | No public post yet |
| Decision rule | Run listening outreach before making content. Capture exact objections and language. |

### H6: Paid Amplification of a Winner

Paid spend should amplify a proven message, not rescue unproven content.

| Field | Value |
| --- | --- |
| Evidence level | 1 |
| External evidence | Flo and Natural Cycles both use paid/creator/performance systems, but their scale came with creative testing and measurement. |
| Internal evidence | No Well Within post has enough intent signal to amplify. |
| Content role | Acquisition test |
| Target metric | Cost per product page view, install, onboarding completion, first observation |
| Visual system | Winning organic Reel variant only |
| Decision rule | Spend $0 until attribution is repaired and one organic post earns a concrete intent signal. |

## Retired Patterns

These are not banned forever, but they are no longer default automation output:

- "Start with one observation" as a repeated premise.
- Broad beginner reassurance carousels.
- Text-only quote or reframe images.
- Glossary carousels.
- Botanical visual systems as the main identity.
- Abstract privacy posts without a sharper user fear.
- App feature explanations without a user job, hook, or behavior.

## Required Pre-Draft Gate

Before any package is drafted, answer:

1. Which hypothesis does this test?
2. What would make us stop this line of content?
3. What exact user belief or behavior does it try to change?
4. What metric decides whether it worked?
5. What did the last three related posts do?
6. Is this a native Instagram idea or a doc disguised as a post?

If any answer is missing, produce a research or measurement task instead of content.
