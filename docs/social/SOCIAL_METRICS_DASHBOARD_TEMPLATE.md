## Decision

Choose one:

- `scale`: repeat the same audience/job/format with one controlled variable changed.
- `iterate`: keep the hypothesis but change hook, format, proof, or CTA.
- `archive`: weak signal; do not repeat unless new evidence appears.
- `invalid`: data missing, claim risk, wrong audience, or measurement failure.

## Rate Calculations

Calculate when data is available:

- Save rate: saves / reach
- Share rate: shares / reach
- Profile-visit rate: profile visits / reach
- Follow rate: follows / profile visits
- Click-through rate: link taps / profile visits
- Install rate: installs / App Store product-page views
- Activation rate: first observations / installs
- D7 retention rate: D7 retained / installs

## No-Slop Gate

Do not generate the next package until the prior post has either:

- 7-day metrics filled in, or
- metric fields marked `unavailable` with the reason, and
- a decision of `scale`, `iterate`, `archive`, or `invalid`.
